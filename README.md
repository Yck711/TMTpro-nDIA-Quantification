# TMTpro-nDIA precursor quantification

Quantify TMTpro 18-plex reporter ions from DIA-NN identifications and the original mzML file. The workflow matches each precursor to candidate MS2 scans, corrects reporter-ion isotope impurities, calculates an MS1 precursor ion fraction (PIF), and assigns one MS2 scan to at most one precursor.

This is the locked quantification method (2026-08-27). It does **not** apply the later figure filters (PIF ≥ 0.70 and removal of the lowest 10% intensity). Those filters, and the earlier all-in-one script `tmt_quant_linear_075_max_yck.py`, are not part of this result.

Commands, input formats, and output columns are in [USAGE.md](USAGE.md).

## What you get

One row per quantified precursor:

- the MS2 scan used for quantification
- precursor ion fraction (`Precursor.PIF`)
- official TMTpro 18-plex isotope-corrected reporter intensities

A precursor with no usable MS1 bracket, or that loses every candidate scan to another precursor, is absent from the final table.

```text
DIA-NN report.parquet + mzML
        │
        ▼
1. extract_candidate_ms2_raw_reporters.py
        │   precursor × candidate MS2, raw 18 reporter intensities
        ├──────────────────────────────┐
        ▼                              ▼
2. apply_official_tmtpro18_            3. calculate_precursor_ms2_pif.py
   isotope_correction.py                  MS1 PIF for every candidate pair
        │                              │
        └──────────────┬───────────────┘
                       ▼
4. build_all_species_maxpif_10ppm_corrected_18channel_master.py
        │   one highest-PIF MS2 per precursor (shared MS2 still allowed)
        ▼
5. make_strict_one_to_one_reassigned_quant_and_plot.py

```

Steps 2 and 3 are independent. Both read the CSV from step 1. Step 4 needs both outputs. Step 5 needs the step-4 table, the step-3 PIF table, and the step-2 corrected table.

Run one DIA-NN `Run` and its matching mzML at a time. Do not concatenate runs.

| Step | Script | Role |

| 2 | `apply_official_tmtpro18_isotope_correction.py` | Correct the 18 raw reporter channels with the embedded official TMTpro isotopic distribution. |

Publish `TMTpro18_official_isotopic_distribution_and_correction_matrix.xlsx` with these scripts. It contains the official TMTpro 18-plex isotopic distribution, the correction matrix A, and its inverse. Step 2 does not read this workbook: the same values are embedded in `apply_official_tmtpro18_isotope_correction.py`. Files named `official_tmtpro18_correction_matrix_used.xlsx` are generated by each run. Do not publish those copies in place of the locked workbook.

Step 5 also imports three other files that must sit in the **same directory**. They are not extra quantification methods:

## Method, short version

**Candidate MS2.** The scan retention time is inside the precursor's DIA-NN `RT.Start`–`RT.Stop` interval, inclusive. The precursor M0, or M1 = M0 + 1.00335 / charge, falls inside the isolation window recorded in the mzML.

**Reporter ions.** Eighteen TMTpro channels, from 126 through 135N. Each theoretical m/z ± 5 ppm; all centroid peaks inside that window are summed. Missing peaks are 0.

**Isotope correction.** Official reporter-ion isotopic distribution, with M+ = 100 and N/A entries treated as 0. For each tag the distribution is normalized by its own sum. Observed vector Y = A × true vector X. The reported intensity is inv(A) × Y, then negative values are clipped to 0. Correction does not affect PIF.

**PIF.** Numerator: M0–M4 whose theoretical m/z lies inside the actual isolation window. Each isotope is the nearest positive centroid within ± 10 ppm; equal mass error keeps the more intense peak. Denominator: all positive centroids in that window. Both quantities are linearly interpolated from the flanking MS1 scans to the MS2 retention time. Only `PIF.Status = ok` can be selected. A pair with no target isotope is stored as PIF = 0 and is not selectable.

**Final scan choice.** Each precursor proposes candidate scans in its own order: higher PIF, then higher target-isotope intensity, then more matched isotopes, then smaller absolute RT difference, then smaller scan ID. Each MS2 keeps the higher-priority precursor. A displaced precursor proposes its next scan. The result is one precursor per MS2.

The highest-PIF table from step 4 is only the list of precursors allowed into this assignment. It is not the published quantification table.

## Requirements

- Python 3.10 or newer (`list[str] | None` and `zip(..., strict=True)`)
- Packages: `numpy`, `pandas`, `pyarrow`, `pyteomics`, `openpyxl`, `python-docx`
- Step 5's PDF also needs `matplotlib` and `scipy`
- Centroid mzML. The m/z arrays must be sorted; profile spectra are not supported.
- DIA-NN RT values and mzML scan times must be in the same unit. With `pyteomics` this is minutes for a standard mzML.
- Enough RAM to hold the precursor–MS2 candidate table. Steps 4 and 5 read that table into memory. A large run can produce a CSV of tens of gigabytes.

Install the packages used by steps 1–4:

```bash
python -m pip install "numpy>=1.24" "pandas>=2.0" pyarrow pyteomics openpyxl python-docx
```

Install the plotting packages only if you want the E. coli PDF from step 5:

```bash
python -m pip install matplotlib scipy
```

## What is outside this quantification

- No PIF threshold is applied inside these scripts. Low-PIF precursors remain if their status is `ok`.
- No reporter-intensity percentile filter is applied.
- For the MA plots in this study, the final table was further restricted to rows whose `Protein.Names` contain `ECOLI`, with all 12 experimental channels finite and > 0, then to `Precursor.PIF >= 0.70`, and the lowest 10% by minimum 12-channel intensity was removed. That subset is not produced here. [USAGE.md](USAGE.md) shows the filter as an optional, study-specific post-step.
- Mass-calibrated PIF (3 ppm or 5 ppm) is not used. PIF is matched to uncalibrated theoretical isotope m/z at ± 10 ppm.
- `tmt_quant_linear_075_max_yck.py` is an earlier method (PIF ≥ 0.75 inside quantification, and the maximum of each channel across scans). Do not use it to reproduce this result.
